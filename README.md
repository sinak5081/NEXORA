User Management Web Application
Features:
  - User Registration & Login
  - Profile Management
  - Skills Management
  - Admin Dashboard
  - User Verification System
Technologies:
  Python · Flask · HTML · CSS · JSON
## Installation & Setup

Follow these steps to run NEXORA locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/NEXORA.git
```

### 2. Navigate to the Project Directory

```bash
cd NEXORA
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Initialize User Data

Create a `users.json` file in the project root directory and add:

```json
{}
```

### 7. Run the Application

```bash
python app.py
```

### 8. Open in Your Browser

Visit:

```text
http://127.0.0.1:5000
```

NEXORA should now be running locally!

---

**Note:** Make sure your virtual environment is activated before running the application.
